# Navinci
Eine Fahrrad-App zur Erfassung der Fahrrad-Daten unter Einbeziehung von GPS und Bluetooth:
GPS --> Geschwindigkeit, Distanz, Dauer
Bluetooth --> Speed-Sensor (Fallback), Cadence-Sensor (Trittfrequenz)
Die gesamten Daten werden in einem Verlauf festgehalten mit der Möglickeit einer Zusatznotiz
